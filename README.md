# Assignment 6 — jQuery (Selectors, Effects & Animations)

**SE-2527 MELIS ANEL**

## About the Project

This project was developed as part of Assignment 6 for the Front-End Development course. The main purpose of this assignment is to learn how to use jQuery to make web pages more interactive and dynamic.

Throughout this project, I worked with different jQuery methods and learned how to select HTML elements, change their content and styles, handle user events, and create animations. Each task focuses on a particular feature of jQuery and provides practical experience with it.

The project includes several sections. First, it introduces the basic setup of jQuery and the use of selectors. Then, it demonstrates different visual effects, such as showing and hiding elements, fading images, and creating sliding panels. The next section focuses on DOM manipulation, including adding and removing elements, changing image and link attributes, and working with user input through forms.

Another important part of the project is animation. I created examples that demonstrate how to change the size, position, and transparency of elements. These examples include both simple animations and several animations performed in sequence or combined together.

For the final part, I decided to develop all three suggested mini-projects instead of choosing only one. They include an interactive Accordion Menu, an Image Gallery with clickable and resizable pictures, and a Bouncing Ball animation with Start, Stop, and Reset buttons.

To make the website easier to use, I also created a shared navigation bar that allows users to move between all tasks. All pages follow the same visual design, using an antique white background with soft blue and lavender colors.

Overall, this project helped me understand the basic functionality of jQuery and gain practical experience in creating interactive web pages using HTML, CSS, JavaScript, and jQuery.

## Mini Projects — Task 11

Three interactive mini-projects were developed:

### 1. Accordion Menu
An interactive FAQ menu. Users can expand and collapse sections using jQuery slide effects.

### 2. Image Gallery
An image gallery with fade effects. Users can show and hide the gallery and enlarge individual images by clicking on them.

### 3. Bouncing Ball
An animated ball that moves horizontally and bounces back. The user can start, stop, and reset the animation.
